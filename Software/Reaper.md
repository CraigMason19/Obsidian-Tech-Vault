# Bass

## Recording As Guitar

Record a guitar signal as usual and add the Fx ReaPitch to it. Change the semitones setting to -12.00 (1 Octave). Latency will occur if playing in real time. If you add a Bias FX tone to it or other settings, you can change the sound by choosing where ReaPitch is in the chain

  

If it is first it will detune the recording then apply the effect (softer) or apply the effect and then detune (twangier)**
